# AWS 실습 리소스 정리 체크리스트

**리소스 정리 결과는 과제 실습 종료 후 확인하여 수정한다.**

리전: 서울(`ap-northeast-2`)  
대상 VPC: `vpc-0d1f32a5067485dc1` (`mission-vpc`)  
정리 완료 일시: 확인 후 입력

## 정리 결과

이 실습에서 만든 EC2 인스턴스, 연결 EBS 볼륨, 보안 그룹, 사용자 정의 라우팅 테이블, Public Subnet, Internet Gateway 및 VPC를 아래 순서로 정리한다. 각 항목은 AWS 콘솔에서 상태를 확인한 뒤 표의 **상태**와 **완료 근거**를 갱신한다. Elastic IP, NAT Gateway, 로드 밸런서, RDS 및 스냅샷은 생성 여부를 확인하고, 생성하지 않았다면 **미생성**으로 기록한다.

최종 확인 시에는 서울 리전의 실습 리소스 목록과 Billing 화면을 확인하고, 확인 시각·표시 금액·남은 리소스를 마지막 표에 기록한다. 결제 화면의 사용량은 늦게 반영될 수 있으므로 이후 한 번 더 확인한다.

다른 실습 또는 기본 VPC의 리소스는 삭제하지 않는다. 특히 `rtb-0174f1f52b4f98572`는 실습 VPC의 **기본 라우팅 테이블**이므로 별도로 삭제하려 하지 말고, 해당 VPC 삭제 과정에서 처리되는지 확인한다.
